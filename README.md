# GOV

Basic Python development assignment example.

## What it does

This repository contains a small Python program with basic software functions:

- Addition
- Subtraction
- Multiplication
- Division (with divide-by-zero protection)

## Run the program

```bash
python basic_program.py add 5 3
python basic_program.py subtract 9 4
python basic_program.py multiply 6 7
python basic_program.py divide 10 2
```

## Run tests

```bash
python -m unittest discover -s tests
```
